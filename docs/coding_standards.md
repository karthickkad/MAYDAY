# MAYDAY Coding Standards

## Module Layout

1. Imports
2. Constants
3. Main Class
4. Properties
5. Serialization
6. Utility Methods
7. Comparison Methods
8. Helper Functions
9. Python Special Methods
10. Module Finalization

## Testing

- Every module must have a matching test module.
- New features require tests before merging.

## Style

- Type hints required.
- Docstrings for public APIs.
- Immutable dataclasses where applicable.
- Consistent section separators.
